# ☕ 카페 오기 (Cafe Ogi) 랜딩페이지

따뜻한 브라운 & 크림 톤의 카페 오기(Cafe Ogi) 소개용 원페이지 랜딩페이지예요.

## 미리보기

`index.html`을 브라우저로 열면 바로 확인할 수 있어요.

## 구성

- **Hero** — 카페 이름, 태그라인, 메뉴 보기 CTA 버튼
- **소개** — 카페 한 줄 소개
- **메뉴** — 커피 · 디저트 대표 메뉴 6종 (사진 없이 아이콘으로 표현)
- **영업시간** — 요일별 영업시간 안내
- **오시는 길** — 주소, 연락처, SNS 링크

## 기술 스택

- HTML5
- CSS3 (프레임워크 없이 순수 CSS, 반응형 레이아웃)
- [Google Fonts](https://fonts.google.com/) — Gowun Batang, Nanum Gothic

## 파일 구조

```
cafe-landing-page/
├── index.html
├── style.css
└── README.md
```
